HOLLOW KNIGHT ARENA — SPRITE CROPS
===================================
Each PNG is an individual crop from the uploaded sprite-sheet preview.
PNG files use RGBA transparency; the checkerboard background was removed where detected.
Folders are organized by sprite category.

IMPORTANT SOURCE LIMITATION:
The source was a small JPEG screenshot (515x482), not an original sprite atlas.
Compression and low resolution limit the recovered detail. These files are separated crops,
not reconstructed high-resolution original art. Inspect edge pixels before shipping.
